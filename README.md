# Distances to logistic regression

Animation for my MSc thesis defence (distance-based GLMs, credit risk).

▶ **[Watch the animation](https://eliazanna.github.io/distances-to-logistic/)** (30 s)

Simulated data (36 firms, 3 predictors). From Euclidean distances alone, classical MDS recovers the original predictors up to rotation and translation, so a GLM on the principal coordinates (DB-GLM) gives exactly the logistic regression fit.

`mds_anim.py` reproduces the video (Python, NumPy/SciPy, Matplotlib, ffmpeg).
